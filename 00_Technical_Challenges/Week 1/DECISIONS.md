## Retrieval, week 1

**What I changed**

> I removed the table of contents by removing the first 300 lines of the file.

**Why**

> There were multiple questions I tested that were choosing parts of the table of contents.
> Question 3: How do HTTPS and TLS relate? How should code with concurrency need to be kept safe? How should UUIDs be used?
> Question 4: What is the link to OWASP's Internet of Things documentation?
> Even when there is a match, the table of contents doesn't hold information that helps with the answer and thus it ends up being a false positive. Removing it made sense in the current situation.


**What would change my mind**

> I would consider undoing it if I realized that the table of contents contains information that could be used for the answers. For example if the table of contents could be used to point the user to the specific location in the text file, then chunking and storing the table of contents or even using it in a different data source might be useful.
